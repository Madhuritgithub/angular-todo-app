# ✅ Angular To-Do App

This is a simple and fully functional **To-Do App** built with Angular using the **standalone component approach** (no modules). You can add and delete tasks easily.

🔗 **Live Demo:**  
[Click here to open the app](https://madhuritgithub.github.io/angular-todo-app/)

---

## 📌 Features
- Add a task
- Delete a task
- Real-time updates
- Clean UI with responsive design

---

## 📦 Tech Stack

- Angular 16+
- Standalone components
- HTML + CSS

---

## 🚀 How to Run Locally

```bash
git clone https://github.com/Madhuritgithub/angular-todo-app.git
cd angular-todo-app
npm install
ng serve
